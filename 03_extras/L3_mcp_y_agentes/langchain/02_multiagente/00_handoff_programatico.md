# Handoff programático

## Objetivo

Entrega una tarea o resultado entre dos responsabilidades.

```mermaid
flowchart LR
    A[Entrada] --> B[Handoff programático]
    B --> C[Salida]
```

## Explicación

Un handoff necesita input, output y criterio de cierre explícitos.

## Práctica

Marcá qué dato recibe el segundo agente.
