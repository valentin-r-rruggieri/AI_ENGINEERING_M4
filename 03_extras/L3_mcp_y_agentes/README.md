# L3: MCP y agentes

## Orden sugerido

1. `mcp`: conceptos de servidor, tools, resources, prompts, transportes y seguridad.
2. `fastmcp`: publicación y consumo de un MCP real por STDIO y HTTP.
3. `fastapi`: endpoints, Pydantic, asincronía y montaje de MCP.
4. `langchain`: prompts, tools, agentes y multiagente.
5. `langgraph`: estado, nodos, routing, handoffs y tools MCP.
6. `pydantic_ai`: outputs tipados, dependencias, tools y MCPToolset.

Después del servidor completo de MCP y del servicio FastAPI, continuá en
`../PI_legalmove` para abrir la entrega oficial de LegalMove.

Antes del proyecto, recorré `resumen/`. El caso `08_agente_fastmcp_real.py` es
la demostración completa recomendada: servidor FastMCP real, cliente MCP,
LangChain y salida Pydantic.
