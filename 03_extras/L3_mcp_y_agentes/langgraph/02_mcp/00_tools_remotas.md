# Tools MCP remotas

## Objetivo

Consume una capacidad MCP dentro de un grafo.

```mermaid
flowchart LR
    A[Entrada] --> B[Tools MCP remotas]
    B --> C[Salida]
```

## Explicación

La ubicación remota no debe cambiar el contrato de entrada y salida.
