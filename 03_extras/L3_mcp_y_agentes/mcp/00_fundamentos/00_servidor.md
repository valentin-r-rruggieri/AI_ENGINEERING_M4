# Servidor MCP mínimo

## Objetivo

Este script crea el contenedor que publica capacidades MCP.

```mermaid
flowchart LR
    A[Host o cliente] --> B[Servidor MCP]
    B --> C[Capacidades]
```

El servidor no es un LLM: registra herramientas, resources y prompts para que otro proceso los descubra.

## Práctica

Cambiá el nombre del servidor y explicá qué responsabilidad tendría.
