# Tool MCP

## Objetivo

Publica una función con argumentos y resultado explícitos.

```mermaid
flowchart LR
    A[Argumento] --> B[Tool] --> C[Resultado]
```

Una tool consulta datos, calcula o ejecuta una acción; el modelo no debe inventar el resultado.

## Práctica

Probá una entrada válida y otra inexistente.
