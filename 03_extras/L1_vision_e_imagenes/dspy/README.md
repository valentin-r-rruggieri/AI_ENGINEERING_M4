OpenAI mediante DSPy; sin `OPENAI_API_KEY` los scripts muestran el objeto preparado.

```powershell
pip install -r 03_extras/L1_vision_e_imagenes/dspy/requirements.txt
$env:OPENAI_API_KEY="tu-clave"
python 03_extras/L1_vision_e_imagenes/dspy/00_fundamentos/00_signature.py
```
