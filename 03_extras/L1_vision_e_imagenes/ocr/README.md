# OCR con Pillow, OpenCV y Tesseract

Recorrido local para preparar imágenes, extraer texto y detectar resultados que necesitan
revisión. Requiere instalar Tesseract en Windows además del paquete `pytesseract`.

```powershell
pip install -r 03_extras/L1_vision_e_imagenes/ocr/requirements.txt
python 03_extras/L1_vision_e_imagenes/ocr/00_preprocesamiento/00_pillow_grises.py
```

Los scripts reutilizan los formularios limpio y borroso de L1.
