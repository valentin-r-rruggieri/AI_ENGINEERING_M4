# Kubernetes: Deployment, Service y probes

Ejercicios para leer y validar manifiestos de un servicio de inferencia. No crean un clúster
ni aplican recursos automáticamente.

```powershell
pip install -r 03_extras/L5_adaptacion_y_despliegue/kubernetes/requirements.txt
python 03_extras/L5_adaptacion_y_despliegue/kubernetes/00_fundamentos/00_leer_deployment.py
```

Después de revisar los YAML, se pueden aplicar manualmente con
`kubectl apply -f 03_extras/L5_adaptacion_y_despliegue/kubernetes/02_en_marcha/` sobre un clúster local.
