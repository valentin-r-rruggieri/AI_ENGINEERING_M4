# Casos de prueba

Estas imágenes son documentos sintéticos, sin datos personales ni secretos.

- `caso_simple`: contrato de servicios con cambios de monto y vencimiento.
- `caso_complejo`: acuerdo de confidencialidad con una modificación, una eliminación y una adición.

Cada `expected.json` es la referencia humana para las pruebas y la demo. La salida de un modelo puede variar levemente en el texto, pero debe conservar los tres campos y los cambios materiales.
