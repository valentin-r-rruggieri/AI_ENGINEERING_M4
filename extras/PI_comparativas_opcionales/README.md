# Comparativas opcionales de LegalMove

Este material es didáctico y no forma parte de la entrega evaluable. La única
entrega oficial está en `proyecto_integrador/PIM4_legalmove/`.

Estas cuatro carpetas comparan el mismo caso con distintas arquitecturas:

1. `langchain`: agente y tools con LangChain.
2. `langgraph`: estado, routing y nodos con LangGraph.
3. `pydantic_ai`: agentes tipados y salida `ContractChangeOutput`.
4. `langfuse`: instrumentación del flujo completo.

Instalá `requirements.txt` y ejecutá un archivo por vez. La comparación debe centrarse
en el control del flujo, la validación y la observabilidad, no en cambiar el problema.
