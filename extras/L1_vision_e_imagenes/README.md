# L1: IA que ve y crea

## Orden sugerido

1. `pydantic`: contratos y validación de las salidas.
2. `openai`: cliente, visión, Base64, salida estructurada y generación de imágenes.
3. `google_gemini`: análisis visual y extracción JSON para comparar proveedores.
4. `ocr`: preprocesamiento, Tesseract y control de calidad.
5. `dspy`: signatures y salidas estructuradas.

Terminá con los ejercicios `en_marcha` de OpenAI, Gemini y OCR. El resultado esperado
es un pipeline visual que devuelve información validada.
