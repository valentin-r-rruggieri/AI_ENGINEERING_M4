# LangChain: modelos, tools y agentes

Recorrido actualizado para LangChain 1.x. Los ejemplos locales muestran prompts y tools;
los agentes reales requieren `OPENAI_API_KEY`.

```powershell
pip install -r extras/L3_mcp_y_agentes/langchain/requirements.txt
$env:OPENAI_API_KEY="tu-clave"
python extras/L3_mcp_y_agentes/langchain/00_fundamentos/00_modelo_prompt.py
```

Terminá con `03_en_marcha/agente_con_tool.py`. La implementación completa de LegalMove
está separada en `../../PI_legalmove/langchain`.
