# LangGraph: estado, nodos y routing

Recorrido por grafos pequeños y explícitos. Los primeros ejemplos son completamente locales;
los nodos con modelo requieren `OPENAI_API_KEY`.

```powershell
pip install -r extras/L3_mcp_y_agentes/langgraph/requirements.txt
python extras/L3_mcp_y_agentes/langgraph/00_fundamentos/00_estado_y_nodos.py
```

Terminá con `03_en_marcha/flujo_con_routing.py`. La implementación completa de LegalMove
está separada en `../../PI_legalmove/langgraph`.
