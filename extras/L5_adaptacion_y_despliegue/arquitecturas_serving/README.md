# Arquitecturas de serving: servidor y serverless

Ejercicios locales para razonar sobre carga del modelo, cold starts, costos, latencia y
concurrencia. No despliegan recursos cloud ni generan gastos.

```powershell
python extras/L5_adaptacion_y_despliegue/arquitecturas_serving/00_fundamentos/00_servidor_vs_serverless.py
```

El integrador produce una recomendación a partir de características de la carga.
